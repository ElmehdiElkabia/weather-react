# Weather React 🌤️

A React weather application built to practice API integration, asynchronous data fetching, and responsive UI development.

## About

The application displays weather information through a simple React interface and demonstrates how a frontend application consumes external weather data.

## Features

- Weather data search
- API integration
- Dynamic weather information
- Responsive interface
- React component-based architecture

## Tech Stack

- React
- JavaScript
- CSS3
- Weather API

## Topics

`react` `javascript` `weather-app` `api` `rest-api` `frontend` `responsive-design`

## Getting Started

```bash
git clone https://github.com/ElmehdiElkabia/weather-react.git
cd weather-react
npm install
npm start
```
